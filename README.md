# Task Manager App

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

## Features
- Add / delete / toggle task
- Filter tasks (All / Completed / Pending)
- LocalStorage persistence
- Form validation

## How to Run
npm install
npm run dev

## Architecture
- Custom hook for state management (useTasks)
- Component-based structure
- Separation of concerns (types, hooks, components)
